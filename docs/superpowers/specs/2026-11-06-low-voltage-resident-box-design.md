## 二、关键决定

### 2.1 用 DOM + 百分比定位，不用画布

高压柜体页用 Leafer 画布，是因为要做拖拽、画线、层级遮挡。低压外部场景只有
「选工具 → 点位置」和「按顺序点三个热区」，没有拖拽。

因此采用与 `/HSO`、`HMiddleArea.vue` 相同的 DOM 方案：

```
.scene-group  { position: relative; display: inline-block; }
.scene-bg     { max-width: 90vw; max-height: 85vh; display: block; }
```

容器尺寸由内部 `<img>` 的自然渲染尺寸决定，所有叠加元素用百分比相对它定位 ——
窗口缩放时整体等比变化，坐标不用换算。

### 2.2 两个步骤共用一个页面

步骤 3 和步骤 4 是同一个场景的两个阶段，不拆成两个页面。完成步骤 3 后：

1. 提交步骤 3
2. 从 `localStorage` 的 `experimentSteps_<experimentId>` 里找 `stepOrder === 4`
3. `router.replace` 把 URL 的 `stepId` 换成步骤 4 的 id

组件不重新挂载，场景原地推进到验电阶段；刷新后按 URL 里的 `stepId` 恢复到正确阶段。

### 2.3 三步式验电与高压完全同构

高压（`HMiddleArea.vue`）的实现是：

```
vtStep 0 → 点插座 → 1 → 点柜体热区 → 2 → 再点插座 → 3 → 完成
```

低压照搬这个状态机，只把第二段的热区从「柜体区域」换成「表箱门把」：

```
vtStep 0 → 点排插 → 1 → 点表箱门把 → 2 → 再点排插 → 3 → 完成
```

顺序错了就把 `vtStep` 归零并计一次错误 —— 与高压一致。

### 2.4 排插放在背景左上角

与高压一致：排插是场景里的一个独立元素，不画在背景图里，用百分比定位叠在背景上：

```js
export const POWER_SOCKET_STYLE = { left: '2%', top: '12%', width: '7%' }
```

具体数值在实现时按素材微调，集中在配置文件里。

## 三、交互设计

### 3.1 步骤 3：架设围栏并悬挂标识牌

左侧工具栏三个工具：**围栏**、**有电危险牌**、**有人工作牌**。

| 操作 | 结果 |
| --- | --- |
| 选「围栏」→ 点地面 | 左右两半围栏同时落位（`barLeftFence` + `barRightFence`） |
| 选「有电危险牌」→ 点表箱区域 | 牌挂上表箱左侧 |
| 选「有人工作牌」→ 点表箱区域 | 牌挂上表箱右侧 |
| 三样都放完 | 自动提交步骤 3，推进到步骤 4 |

未选工具就点场景、或选错工具点错位置 → 提示 + 计一次错误。

### 3.2 步骤 4：三步式验电

右侧工具栏一个工具：**验电笔**。验电笔跟随鼠标移动（尖端对准光标，与高压一致）。

1. 点「验电笔」图标 → 进入验电模式
2. 点**排插** → `vtStep = 1`
3. 点**表箱门把**（此时门把热区高亮显示）→ `vtStep = 2`
4. 再点**排插** → `vtStep = 3`，验电完成

任一环节点错位置 → `vtStep` 归零、提示、计一次错误。

验电完成后提交步骤 4，弹出「外部操作完成」提示（内部场景下一期实现）。

## 五、数据与存档

### 5.1 存档结构

```js
{
  stage: 3 | 4,          // 当前阶段
  placed: [false, false, false],  // 围栏 / 有电危险牌 / 有人工作牌
  vtStep: 0,             // 验电进度 0-3
  vtDone: false
}
```

`saveDraft` 写入 `resultData`；`getStepDraft` 恢复。

### 5.2 步骤推进

完成步骤 3 后提交（`submitStep`，`status: 1`），再从 `experimentSteps_<id>` 找
`stepOrder === 4` 的 `stepId`，`router.replace({ query: { experimentId, stepId: 新id } })`。

**找不到步骤 4 时**：提示「未找到下一步骤，请确认数据库已执行第 4 步脚本」并停留在步骤 3，
不带着空 `stepId` 推进 —— 那会让页面既存不了档也提交不了。

### 5.3 分数

与现有页面一致：`score = max(0, 100 - error_count * 10)`。

## 七、错误处理

| 场景 | 处理 |
| --- | --- |
| 未选工具就点场景 | 提示「请先从工具栏选择工具」+ 计一次错误 |
| 选错工具点错位置 | 提示「请选择正确的放置位置」+ 计一次错误 |
| 验电顺序错 | `vtStep` 归零 + 提示 + 计一次错误 |
| 未放完围栏/标识牌就点验电笔 | 提示「请先完成围栏与标识牌放置」+ 计一次错误 |
| 存档恢复失败 | 显式失败面板 + 「重新加载」+ 全屏遮罩挡住场景，避免空状态下覆盖存档 |
| 缺少实验元数据 | 提示「请从实验选择页进入低压场景」+ 返回按钮 |
| 找不到步骤 4 | 提示并停留（见 5.2） |

## 八、验证方式

1. `/LTS` 提交后进入 `/LRB`，URL 带步骤 3 的 `stepId`
2. 从实验选择页「继续实验」→ `nextStepOrder = 3` → 进入 `/LRB`
3. 选围栏点地面 → 左右两半围栏同时出现
4. 未选工具点场景 → 提示 + 错误次数 +1
5. 两块牌分别挂到表箱上
6. 三样放完 → 自动提交步骤 3 → URL 的 `stepId` 换成步骤 4
7. 点验电笔 → 点排插 → 点门把（热区高亮）→ 再点排插 → 验电完成
8. 验电顺序错（跳过门把直接点排插）→ 归零 + 提示
9. 中途保存 → 刷新 → 恢复到相同阶段与进度
10. 完成步骤 4 → 提交成功，弹出「外部操作完成」
11. 数据库里该实验的步骤 3、4 记录 `status = 1`，分数按公式落库
12. 窗口缩放时场景与热区同步等比变化，不错位

## 九、待确认风险
