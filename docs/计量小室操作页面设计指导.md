## 一、当前项目状态速览

| 模块                    | 状态      | 说明                                                   |
| :---------------------- | :-------- | :----------------------------------------------------- |
| `HCabinetLocalView.vue` | ✅ 已有   | 柜体局部操作页，已实现步骤3+4（设围栏+挂牌、三步验电） |

## 三、画布分层设计

LeaferJS 画布内部划分为三层：

| 层级       | 用途       | 内容                                                                 |
| :--------- | :--------- | :------------------------------------------------------------------- |
| **背景层** | 静态场景图 | 计量小室背景图（按步骤切换：未挂表→已挂表→已接线→已装标识牌→已盖盖） |
| **交互层** | 可交互元素 | 接线盒开关、接线孔热区、排座热区、挂表区域热区、确认按钮             |
| **覆盖层** | 动态反馈   | 鼠标跟随导线、已连接的导线路径、临时高亮                             |

**背景图切换流程**：

```
初始：MeteringRoomNoMeter.png
    ↓ 挂表完成
MeteringRoomWithMeter.png
    ↓ 7根导线接完 + 6芯信号线接完
MeteringRoomWired.png
    ↓ 扎带标识牌放置完成
MeteringRoomWithCableTies.png
    ↓ 接线盒盖盖完成
MeteringRoomCovered.png（盖盖后的计量小室）
```

## 四、步骤详细设计

### 步骤 2.6.2：挂终端

**触发条件**：三步验电完成后自动进入计量小室，显示未挂表背景。

**交互流程**：

1. 用户点击右侧工具栏「三相三线智能电表」图标
2. 电表图标跟随鼠标移动（复用现有鼠标跟随逻辑）
3. 用户移动到画布上的「挂表区域」热区再次点击
4. 校验通过：
   - 背景图切换为 `MeteringRoomWithMeter.png`
   - 画布上方出现 Vue 组件提示（内容待定）
   - 记录 `meterPlaced: true`
5. 校验失败：
   - 提示错误信息
   - 记录错误次数（`errorCount++`）
   - 电表图标消失（或回到工具栏）

**交互层元素**：

- `挂表区域热区`：透明 Rect，覆盖背景图上标注的挂表区域

```typescript
// 点击电表 → 鼠标跟随
const onMeterClick = () => {
  isMeterFollowing = true;
  // 创建跟随的电表图片
  const meterFollower = new Image({ url: meterImage, width: 80, height: 120 });
  // 绑定鼠标移动事件...
};

// 点击挂表区域
dropZone.on("click", () => {
  if (isMeterFollowing) {
    // 放置成功
    switchBackground("MeteringRoomWithMeter.png");
    context.meterPlaced = true;
    isMeterFollowing = false;
    // 触发成功提示
    showPrompt("电表挂载成功");
  }
});
```

### 步骤 2.6.4：接电压、电流进出线（7根导线）

**接线顺序**（从右到左）：

| 顺序 | 导线规格      | 起点（接线盒） | 终点（电表） |
| :--- | :------------ | :------------- | :----------- |
| 1    | 4.0红黑色导线 | 接线盒孔1      | 电表孔1      |
| 2    | 4.0红色导线   | 接线盒孔2      | 电表孔2      |
| 3    | 2.5红色导线   | 接线盒孔3      | 电表孔3      |
| 4    | 2.5绿色导线   | 接线盒孔4      | 电表孔4      |
| 5    | 4.0黄黑色导线 | 接线盒孔5      | 电表孔5      |
| 6    | 4.0黄色导线   | 接线盒孔6      | 电表孔6      |
| 7    | 2.5黄色导线   | 接线盒孔7      | 电表孔7      |

**交互流程**（严格顺序）：

1. 用户点击右侧工具栏「剥线钳」图标 → 图标边框高亮
2. 用户点击对应导线图标（如「4.0红黑色导线」）→ 记录 `selectedWire`
3. 用户点击右侧工具栏「十字螺丝刀」图标 → 螺丝刀跟随鼠标
4. 用户点击接线盒上的**接线孔**（起点孔）→ 导线从该孔伸出跟随鼠标
5. 用户点击电表上的**接线孔**（终点孔）→ 完成一根导线的绘制
6. 重复 1-5 步，依次完成 7 根导线
7. 全部完成后弹窗提示

**Pinia 状态机**：

```typescript
// stores/experiment.ts
state: {
  wiringStep: 'idle' | 'plier_selected' | 'wire_selected' | 'screwdriver_active' | 'wire_drawing',
  selectedWire: null | { spec: string, color: string, pathColor: string, pathWidth: number },
  startHole: null | { id: string, x: number, y: number },
  connectedWires: [] as { from: string, to: string, spec: string }[],
  expectedWires: ['4.0红黑色', '4.0红色', '2.5红色', '2.5绿色', '4.0黄黑色', '4.0黄色', '2.5黄色']
}
```

**LeaferJS 交互逻辑**：

```typescript
// 接线孔点击
hole.on("click", () => {
  const store = useExperimentStore();

  // 状态1：螺丝刀激活 → 点击起点孔
  if (store.wiringStep === "screwdriver_active") {
    store.startHole = { id: hole.id, x: hole.x, y: hole.y };
    store.wiringStep = "wire_drawing";
    // 创建跟随鼠标的导线（从起点孔伸出）
    startWireFollower(hole.x, hole.y, store.selectedWire.pathColor);
    return;
  }

  // 状态2：导线绘制中 → 点击终点孔
  if (store.wiringStep === "wire_drawing") {
    const from = store.startHole;
    // 绘制最终导线
    drawWire(from.x, from.y, hole.x, hole.y, store.selectedWire);
    store.connectedWires.push({
      from: from.id,
      to: hole.id,
      spec: store.selectedWire.spec,
    });
    // 重置状态
    store.wiringStep = "idle";
    store.startHole = null;
    hideWireFollower();
    // 检查是否7根全部完成
    checkAllWiresConnected();
  }
});
```

**导线绘制**（LeaferJS Path）：

```typescript
function drawWire(x1: number, y1: number, x2: number, y2: number, wire: Wire) {
  const path = new Path({
    path: `M ${x1} ${y1} Q ${(x1 + x2) / 2} ${Math.min(y1, y2) - 40} ${x2} ${y2}`,
    stroke: wire.pathColor,
    strokeWidth: wire.pathWidth,
    lineCap: "round",
  });
  overlayLayer.add(path);
  // 存储路径引用以便后续清除或保存
}
```

5. **再接左侧（电表）**：电表孔水平排列，点击信号线某芯 → 点击电表对应孔

## 八、关键注意事项

1. **交互模式统一**：全部采用「点击工具栏 → 跟随鼠标 → 点击目标放置」模式，与围栏、验电笔保持一致
2. **热区设计**：接线孔、排座孔等位置使用透明 Rect 热区，后期根据实际背景图微调坐标
3. **状态机设计**：接线流程的状态机严格防止用户跳步
4. **进度恢复**：所有状态（开关位置、已接导线、铅封位置）存入 `user_experiments.draft_data`
5. **错误记录**：每次错误操作记录 `errorCount`，便于教学评估
6. **复用现有组件**：PromptModal、鼠标跟随逻辑、三步验电逻辑等尽量复用，减少重复开发
7. **弹窗提示**：每个步骤完成后或进行了错误操作都应有明确的提示，避免用户迷失操作流程
